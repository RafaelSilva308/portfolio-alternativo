# Rafael Silva — Portfolio

Portfolio profissional apresentando serviços de desenvolvimento de sistemas,
SaaS, automação com IA e landing pages, com projetos reais hospedados no
[GitHub](https://github.com/RafaelSilva308).

Construído com React + Vite.

## Rodando localmente

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Publicado automaticamente no GitHub Pages a cada push na branch `master`.
